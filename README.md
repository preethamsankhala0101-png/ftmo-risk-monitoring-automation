# MT5 Trade Risk & Execution Audit System
Automated Python & AI workflow to parse MetaTrader 5 (MT5) trade logs, audit daily drawdown limits (5%), and flag high-slippage execution anomalies across Forex, Commodities (XAUUSD), and Crypto (BTCUSD).

## Features
- **Drawdown Audit:** Flags accounts breaching daily equity threshold limits.
- **Slippage Analysis:** Measures execution latency during high-impact news.
- **AI Integration:** Outputs structured summaries for automated desk reporting.
